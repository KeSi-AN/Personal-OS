# Personal OS

A local-first personal context and assistant layer: observes your computer activity (with your control), remembers it as structured project context, answers questions about your own work, and acts through a permissioned tool registry. Everything runs on your machine.

Status: design phase. See [docs/DESIGN.md](docs/DESIGN.md), [docs/DECISIONS.md](docs/DECISIONS.md), and [docs/DEPENDENCIES.md](docs/DEPENDENCIES.md).
